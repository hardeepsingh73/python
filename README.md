## Learning Path

1. **Day 1 — Fundamentals**: Start with the [Day 1 notes](Day-1/python_language.md) for variables, data types, operators, and input.
2. **Day 2 — Core Programming**: Move on to [Part 1](Day-2/part-1.md) for strings, conditionals, collections, loops, functions, file I/O, and OOP, then [Part 2](Day-2/part-2.md) for a deep dive into lists and tuples.
3. **Day 3 — Collections**: Continue with [Dictionaries](Day-3/part-3-dictionary.md) and [Sets](Day-3/part-4-set.md) for an in-depth look at Python's two remaining core collection types.

## Features

- **Day-by-day structure** — follow a logical learning path from fundamentals to advanced topics
- **Executable examples** — every concept includes runnable Python code with expected output
- **Quick reference** — cheat sheets and summary tables in every section
- **Practice questions** — end-of-chapter exercises and mini projects to reinforce learning
- **Common mistakes** — every section lists frequent pitfalls and how to avoid them

## How to Use

1. Start with the [Day 1 notes](Day-1/python_language.md) to learn the fundamentals.
2. Move on to [Day 2 Part 1](Day-2/part-1.md) for core Python programming.
3. Continue with [Day 2 Part 2](Day-2/part-2.md) for a deeper dive into lists and tuples.
4. Finish with [Day 3 Dictionaries](Day-3/part-3-dictionary.md) and [Day 3 Sets](Day-3/part-4-set.md) for advanced collections.

Run any code snippet directly in the Python interpreter (Python 3.12 or later recommended) or via a file:

```bash
python hello.py
```
