# Python Learning Notes

A structured collection of beginner-friendly Python study guides, written as day-by-day Markdown notes with practical, executable examples.

## Contents

| Day | File | Topics Covered |
|-----|------|----------------|
| Day 1 | [`Day-1/python_language.md`](Day-1/python_language.md) | Python introduction & history, character set, variables, identifiers, data types, keywords, comments, operators, type conversion, `input()`, cheat sheet & practice questions |
| Day 2 | [`Day-2/part-1.md`](Day-2/part-1.md) | Variables & data types, strings, conditionals, lists & tuples, dictionaries & sets, loops, functions & recursion, file I/O, OOP, cheat sheet, practice questions & projects |
| Day 2 | [`Day-2/part-2.md`](Day-2/part-2.md) | Deep dive into lists and tuples: building, indexing/slicing, methods, copying & aliasing, comprehensions, unpacking, nested lists, named tuples, performance & mini project |

## Features

- **Day-by-day structure** — follow a logical learning path from fundamentals to advanced topics
- **Executable examples** — every concept includes runnable Python code with expected output
- **Quick reference** — cheat sheets and summary tables in every section
- **Practice questions** — end-of-chapter exercises and mini projects to reinforce learning

## How to Use

1. Start with the [Day 1 notes](Day-1/python_language.md) to learn the fundamentals.
2. Move on to [Day 2 Part 1](Day-2/part-1.md) for core Python programming.
3. Continue with [Day 2 Part 2](Day-2/part-2.md) for a deeper dive into lists and tuples.

Run any code snippet directly in the Python interpreter (Python 3.12 or later recommended) or via a file:

```bash
python hello.py
```
